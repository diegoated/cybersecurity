# Cybersecurity

My cybersecurity learning, documented as I go. I'm a computer
science student at Texas A&M focusing on cybersecurity. This repo holds my
notes, writeups, and lab work.

## Contents

| Folder | What's in it |
|---|---|
| [overthewire](overthewire/) | Notes and solutions from OverTheWire wargames, focused on Linux and command-line fundamentals |
| [tryhackme](tryhackme/) | Notes from TryHackMe rooms and learning paths |
| [homelab](homelab/) | A virtualized lab for practicing offensive and defensive security, with setup guides, attack writeups, and hardening notes |

## How I use this repo

- Everything is written in my own words while I work, including the
  mistakes and what fixed them.
- Writeups follow the same pattern: the goal, the commands I ran, what
  happened, and what I learned.
- Notes are in Markdown and written in Vim.

## Ethics and scope

All testing happens on platforms built for practice (OverTheWire,
TryHackMe) or in my own isolated lab on machines I own. I don't test
systems I don't have permission to test.

## Tools

Arch Linux, KVM/QEMU, Kali Linux, nmap, SSH, Vim, Git
