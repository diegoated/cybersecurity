# OverTheWire

Notes from the [OverTheWire](https://overthewire.org/wargames/) wargames,
which teach Linux, networking, and security fundamentals by using SSH to connect to
a server and find the passwords for every level.

## Progress

| Wargame | Status | Notes |
|---|---|---|
| Bandit | Level 14 -> Level 15 | [bandit/](bandit/) |

## Format

Each level note follows the same pattern:

- **Goal:** what the level asks for
- **Commands:** what I ran
- **What I learned:** the concept behind it

Level passwords are not included. OverTheWire asks people not to publish
them, and the point is to work through the levels yourself.

## Skills practiced

Linux command line, file permissions, SSH, basic networking, and reading
`man` pages.
